# Tjønnås Website (in progress)
A homepage for the local brand Tjønnås, which is an umbrella for a delicacy shop, a cafè, and a clothes shop. 


Designed from bottom up by me, working with Figma. 

## Tech Stack
- Next.JS
- Tailwind CSS
- Sanity CMS
- Deployed on Vercel
